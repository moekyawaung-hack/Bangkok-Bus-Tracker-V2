# 🇹🇭 Bangkok Bus Tracker App (Final V2)
### Multilingual • GTFS‑Powered • Offline MBTiles • Mobile + CLI

The **Bangkok Bus Tracker App** is a multilingual (English / Myanmar / Thai) public‑transport navigation system for Bangkok.  
It integrates **GTFS static data**, **GTFS‑Realtime**, and **offline MBTiles maps** to provide bus routing, stop lookup, and live tracking.

---

## ✨ Features
- 🚌 GTFS‑Powered Bus Routes (BMTA)
- 🛰️ Live Bus Tracking (GTFS‑Realtime)
- 🌏 Multilingual UI (EN/MM/TH)
- 🗺️ Offline MBTiles Map Viewer
- 📍 Stop overlay + 🚌 live bus markers
- 📱 Mobile App (Kivy → Android APK)
- 💻 CLI Version for debugging
